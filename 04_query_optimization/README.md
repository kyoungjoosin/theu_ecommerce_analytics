# 자사몰 쿼리 최적화

## 배경

비효율적인 테이블 조인 구조로 품목 조회 / 검색 / 장바구니 등  
주요 페이지 로딩 속도가 3~4초 지연.  
거래처 담당자의 지속적인 민원 발생 후 개선 착수.

## 접근 방식

**문제 진단**
- 주요 테이블 행 수 확인 → 데이터 많은 테이블이 첫 번째 JOIN 대상이었음

**개선 1. JOIN 순서 재설계**
- 데이터 적은 테이블을 먼저 JOIN하는 순서로 변경
- 중간 결과셋 크기를 줄여 이후 JOIN 비용 감소

**개선 2. 반복 서브쿼리 → 집계 테이블로 대체**
- 페이지 로드마다 실행되던 서브쿼리를 사전 집계 테이블로 분리
- 윈도우 함수 미지원 환경(MySQL 5.x)에서 집계 테이블로 동일 효과 구현

## 결과

| 구분 | 개선 전 | 개선 후 |
|------|--------|--------|
| 페이지 로딩 속도 | 3~4초 | 0.3초 |
| 개선율 | — | **90%** |

품목 조회 / 검색 / 장바구니 등 주요 페이지 전반 적용.

## 한계

- 주기적 쿼리 성능 점검 프로세스 필요성 인지
