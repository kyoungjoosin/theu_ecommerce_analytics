# 개인화 품목 조회를 활용한 주문 경험 개선

## 배경

신제품 우선 노출 목적의 일관된 정렬 방식으로  
구매자가 원하는 품목을 한 번에 찾기 어려운 구조.

## 분석 흐름

```
STEP 1. 최근 1년 주문 데이터 기반 유저별 주문 빈도 순위 산출
       → member_product_rank 테이블 생성 (주 1회 자동 갱신)

STEP 2. 개인화 정렬 적용 후 주문 소요시간 전후 비교
       → 로그인 → 주문 완료 소요시간을 merge_asof로 사용자별 매핑
       → 기존 고객 / 신규 고객 분리 분석
```

## 결과

분석 대상: 2,388명 / 비교 기간: 25년 11~12월 vs 26년 1~2월

| 구분 | 개선 전 | 개선 후 | 변화 |
|------|--------|--------|------|
| 기존 고객 소요시간 | 3.08분 | 2.87분 | **-6.8%** |
| 신규 고객 소요시간 | — | 5.29분 | 개인화 효과 없음 |
| 주문 전환율 | 51.47% | 51.95% | +0.48%p |
| 주문당 상품 수 | 1.40 | 1.39 | 유의미한 변화 없음 |

개인화 정렬이 구매 유도보다 **탐색 효율 개선**에 기여.
