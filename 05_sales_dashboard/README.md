# 자사몰 영업 현황 대시보드 구축

## 개요
영업운영팀의 수동 ERP 엑셀 집계 업무를 대체하기 위해
현업 인터뷰 기반으로 지표를 기획하고 단독 구축한 Looker Studio 대시보드.

IT팀 2분기 사업계획 과제로 진행.

## 배경 및 문제
- 영업운영팀이 자사몰 영업 현황을 ERP에서 매번 수동 엑셀 다운로드로 관리
- 거래처 이탈 여부, 쿠폰 사용 패턴, 5,999원 주문 패턴 등
  운영 인사이트를 실시간으로 파악하는 것이 불가능한 구조

## 기술 스택
MySQL → Google Sheets (Apps Script) → Looker Studio

## 파이프라인 구조
카페24 호스팅 환경 특성상 Looker Studio의 MySQL 직접 연결이 불가하여
아래 방식으로 구성

MySQL (자사몰 DB)
    ↓ 쿼리 실행 (수동 or 스케줄)
Google Sheets (중간 저장소)
    ↓ Looker Studio 데이터 소스 연결
Looker Studio 대시보드

## 대시보드 구성
| 페이지 | 주요 지표 |
|---|---|
| 페이지 1. 매출/주문 추이 | 월별 매출·주문 건수, 쿠폰·예치금 사용 추이 |
| 페이지 2. 거래처 분석 | 매출 Top10, 주문빈도 Top10, 거래처별 월별 평균 |
| 페이지 3. 주문 패턴 분석 | 5,999원 구간, 쿠폰 사용률, 예치금 구매 현황 |

## 핵심 비즈니스 로직
자세한 내용은 docs/business_logic.md 참고

- 취소/반품 구분: 주문 상태 코드 기준으로 취소와 반품을 분리 집계
- 예치금 상품 분리: 예치금 충전 주문을 일반 매출에서 제외하여 순매출 산출
- 거래처 이탈 기준: 최근 주문일로부터 90일 이상 미주문 거래처를 이탈 위험군으로 분류
