# 도매 주문 UI 개선 가설 검증

## 배경

자사몰 도매 주문 등록 시스템이 소매와 동일한 이미지형 UI.  
도매 구매자는 다품목 대량 주문 패턴일 것이라는 가설 하에  
리스트형 UI로 전환 후 실제 주문 데이터로 가설 검증.

## 분석 흐름

```
UI 전환 (이미지형 → 리스트형)
→ wholesale_orders 데이터 집계
→ 주문당 상품 수 / 상품별 주문 수량 분포 확인
→ 대량 구매 패턴 정량화로 가설 검증
```

## 결과

| 구분 | 평균 | 중앙값 | 상위 10% |
|------|------|--------|---------|
| 주문당 상품 수 | 16.9개 | 11개 | 42개 |
| 상품별 주문 수량 | 49.2개 | 20개 | 100개 |

다품목 대량 구매 패턴 확인 → **UI 개선 방향 타당성 검증**.

## 한계

- UI 전환 전 데이터를 사전 확보하지 않아 A/B 테스트 설계 불가
- 사후 검증 시도 중 로그인 시간 미기록으로 소요시간 분석 불가  
  → 이후 개인화 정렬 프로젝트에서 로그인 로그를 성과 지표로 활용하는 방식으로 개선
