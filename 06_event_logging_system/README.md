# 06. 사용자 행동 이벤트 로깅 시스템 구축

## 배경

자사몰에 사용자 행동 데이터를 수집하는 체계가 전혀 없었습니다.
주문·반품 등 결과 테이블은 존재했지만, "유저가 어떤 페이지를 보고, 어떤 상품을 탐색하고,
장바구니에 담았는지"와 같은 행동 데이터는 기록 자체가 되지 않는 구조였습니다.

기존 분석 프로젝트(반품 분석, 개인화 정렬 등)는 전부 결과 데이터만으로 수행한 것이었고,
"왜 이탈했는가", "어디서 전환이 막히는가" 같은 과정 분석은 구조적으로 불가능했습니다.

**⇒ 사용자 행동 흐름을 데이터로 추적할 수 있는 이벤트 로깅 체계를 직접 구축**

---
## 해결 방안
### STEP 1. 이벤트 Taxonomy 설계 — 뭘 수집할 것인가

- 사용자 여정(User Journey) 흐름 기반 수집 대상 이벤트 정의
  - `page_view` → `product_view` → `add_cart` → `purchase`
- 5컬럼 이벤트 스키마 설계

| 컬럼 | 설명 |
|------|------|
| `event_name` | 이벤트 이름 (page_view, add_cart 등) |
| `uniq_id` | 비회원 포함 고유 식별자 |
| `member_id` | 회원 ID (로그인 시) |
| `platform` | PC / Mobile 구분 |
| `properties` | 이벤트 속성 (JSON 문자열, TEXT 타입) |

- 6개 페이지 카테고리, 총 11개 이벤트 정의
- PC/모바일 경로 분리: ~20개 PHP 파일에 로깅 코드 직접 삽입

### STEP 2. 환경 제약 대응 — 외부 툴 없이 어떻게 수집할 것인가

- Amplitude·GA 등 외부 분석 툴 연동 불가 (Cafe24 폐쇄형 환경)
  - → 자체 MySQL 테이블 기반 수집·적재 구조로 설계
- MySQL 5.1.45: JSON 함수 미지원, 윈도우 함수 미지원
  - → `properties` 컬럼을 TEXT에 JSON 문자열로 저장하는 방식으로 우회
  - → 이벤트 속성 분석은 Python으로 JSON 파싱 후 수행

### STEP 3. 집계 파이프라인 구축 — 어떻게 분석 가능하게 만들 것인가

- 목적별 3개 집계 테이블 설계·운영:

| 테이블 | 용도 |
|--------|------|
| `event_daily_summary` | 이벤트별 일별 발생 건수 집계 |
| `daily_kpi` | 핵심 KPI(DAU, 전환율 등) 일별 요약 |
| `return_daily_summary` | 반품 관련 지표 일별 집계 |

- 일배치 자동화
- OS 스케줄러 → 스크립트 → 서버 엔드포인트 호출 방식

---

## 성과

| 구분 | 기존 | 구축 후 |
|------|------|---------|
| 사용자 행동 추적 | 불가 | 페이지뷰→상품조회→장바구니→구매 전환 흐름 추적 가능 |
| 분석 가능 범위 | 결과(주문) 데이터만 | 탐색·이탈 등 과정 데이터까지 확장 |
| 데이터 수집 방식 | 없음 | 11개 이벤트 자동 수집·일별 자동 집계 |
| 플랫폼 구분 | 불가 | PC/모바일 행동 분리 분석 가능 |

---

## 기술 스택

- **로깅 구현**: PHP (Cafe24 환경)
- **데이터 저장**: MySQL 5.1.45
- **집계 자동화**: OS 스케줄러 + 스크립트 기반 배치
- **분석**: Python (Pandas, SQLAlchemy, pymysql)

---


## 레슨런

### Strong
- 분석가가 없던 조직에서 "무엇을 수집해야 하는가"부터 직접 정의
- 설계 → 구현 → 운영까지 End-to-End 단독 수행
- 기존 분석(반품·재구매)이 결과 데이터에 한정되었던 한계를 구조적으로 보완

### Weak
- 수집 체계 구축 단계로, 이 데이터 기반 심층 분석(퍼널·이탈 등)은 진행 중
- purchase 이벤트 일부 누락 이슈 (PG 서버 간 콜백 구조 기인, 보정 방안 검토 중)
- 현재 환경에서 가능한 범위 내 수집·집계 구조를 구현
  - BigQuery·Amplitude 등 분석 환경이 갖춰진다면 이벤트 속성별 심층 분석·실시간 모니터링까지 확장 가능
