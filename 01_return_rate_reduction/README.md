# 반품 축소 테스트 액션

## 배경

매월 지속적인 반품 신청으로 재고 손실 발생.  
7년치 반품 데이터가 쌓여 있었지만 한 번도 정량화된 적 없었음.

## 분석 흐름

```
주관식 반품 사유 텍스트
→ 키워드 매핑 함수로 6개 카테고리 분류
→ 유효기간 만료가 1위 확인
→ 주문 내역 정렬 최신순 변경 테스트 실행
→ 전후 비교 검증 (25년 1~3월 vs 26년 1~3월)
```

## 결과

| 구분 | 2025년 1~3월 | 2026년 1~3월 | 변화 |
|------|------------|------------|------|
| 기준 주문 건수 | 4,634건 | 7,741건 | +67% |
| 전체 반품률 | 7.6% | 5.1% | **-2.5%p** |
| 유효기간 반품률 | 2.24% | 1.10% | **-1.14%p** |
| 처방문제 반품률 | 1.21% | 1.41% | +0.2%p ⚠️ |

주문량이 67% 증가하는 상황에서도 전체 반품률 감소 확인.  
처방문제 반품 소폭 증가 → 영업팀 확인으로 분기 과잉 납품 관행 식별.

## 한계

- A/B 테스트 없이 전후 비교 방식 — 외부 요인 통제 제한적
- 키워드 매핑의 분류 정교도 한계 (형태소 분석 미적용)
